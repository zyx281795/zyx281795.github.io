# 中醫國考智慧系統 - TCM Exam & Herb AI Assistant

## 系統簡介

這是一個基於純 HTML + CSS + JavaScript 開發的中醫藥學習系統，參考「tcm-exam-herb-ai-assistant」的功能與美術設計，整合了「電子書+醫砭」資料夾中的完整資料，包括 300 種常用中藥、413 種醫砭中藥及 721 個方劑。

## 功能特色

- **儀表板**：系統概覽與快速統計
- **國考題庫**：國考題目練習（開發中）
- **醫砭集錦**：完整的醫砭中藥與方劑資料庫 ✨ 新增！
  - 數據規模：413 種中藥 + 721 個方劑
  - 智能搜尋：支援藥名、科屬、功效、主治等關鍵字搜尋
  - 類型篩選：快速切換「全部」、「中藥」、「方劑」
  - 分類篩選：按藥物分類（如利尿通淋、和解少陽等）篩選
  - 詳細資訊：
    - 中藥：科屬、品種來源、性味歸經、功效、主治、用法用量、禁忌、現代藥理
    - 方劑：來源、製法用量、功效、主治、方義、辨證要點、加減、現代應用
  - 精美卡片：綠色（中藥）和藍色（方劑）區分設計
  - 詳情彈窗：點擊查看完整資訊
- **中藥百科**：300 種常用中藥完整資料
  - 搜尋功能：支援藥材名稱、別名、功效等關鍵字搜尋
  - 卡片展示：精美的網格布局
  - 詳情檢視：點擊卡片查看完整藥材資訊
  - 圖片輪播：支援多張藥材圖片切換
  - 無限滾動：自動載入更多藥材
- **模型訓練驗證**：AI 模型訓練功能（開發中）

## 使用方式

### 方法一：直接雙擊運行

1. 找到 `index.html` 檔案
2. 雙擊開啟（將使用預設瀏覽器）
3. 開始使用系統

### 方法二：使用本地伺服器（推薦）

如果遇到 CORS 錯誤（無法載入 JSON 資料），請使用本地伺服器：

**使用 Python：**
```bash
# Python 3
python -m http.server 8000

# 然後在瀏覽器開啟
# http://localhost:8000
```

**使用 Node.js：**
```bash
# 安裝 http-server
npm install -g http-server

# 啟動伺服器
http-server -p 8000

# 然後在瀏覽器開啟
# http://localhost:8000
```

## 注意事項

1. **圖片路徑**：確保 `tcm-exam-herb-ai-assistant/public/herbs/` 資料夾中有藥材圖片
2. **JSON 資料**：
   - `herbs_data.json`（300種藥材）
   - `yibian_data.json`（醫砭資料）
   - 兩個檔案必須與 `index.html` 在同一目錄
3. **瀏覽器限制**：某些瀏覽器可能因安全性限制無法直接載入本地 JSON 檔案，建議使用本地伺服器
4. **圖片載入**：如果圖片無法載入，系統會自動顯示替代圖片
